STUDY ♡ — Guia rápido

COMO ABRIR
1. Extraia o arquivo ZIP.
2. Abra a pasta STUDY no VS Code (Arquivo > Abrir pasta).
3. Abra o index.html com a extensão Live Server (clique com o botão direito > Open with Live Server).
   Também é possível abrir o index.html diretamente no navegador, mas o Live Server é recomendado.

O QUE JÁ FUNCIONA
- Salvar redações no armazenamento local do navegador.
- Listar, ler, editar e excluir redações.
- Pesquisar por título, tema ou conteúdo.
- Filtrar por tema e ordenar.
- Contadores de redações, temas e palavras.
- Revisão orientativa local (extensão, parágrafos e conectivos).
- Exportar e importar backup em JSON.
- Layout responsivo para celular e computador.

IMPORTANTE SOBRE OS DADOS
As redações ficam no localStorage deste navegador e dispositivo. Limpar os dados do navegador pode apagá-las. Use "Exportar backup" regularmente. Para levar seus textos a outro computador, exporte o backup e importe no outro.

SOBRE A REVISÃO
A área "Revisar minha redação" faz verificações simples no próprio navegador. Ela NÃO é uma IA real, não dá nota oficial do ENEM e não substitui uma correção especializada. Para conectar uma IA real futuramente, será necessário um serviço/API e uma chave protegida em um backend — não coloque chaves secretas diretamente no JavaScript do navegador.
